### 🎾 [Pladelo](https://pladelo.com)

**Americano padel tournaments, organized fairly — from the first player to the final results.**

A bilingual (Arabic / English) web app that lets an organizer run a whole Americano padel tournament from a phone.

- **Fair schedules:** everyone plays the same number of games, partners rotate and rests are shared evenly. Every schedule is checked before the organizer approves it.
- **Balanced matches:** optional hidden player levels (A1–D2) keep strong pairs away from much weaker opponents. Players never see the levels.
- **Live results page:** a share link shows the current round and the ranking. Once the tournament ends, it shows the final standings with a league table (win 3 · draw 1 · loss 0).
- **Organizer tools:** round timer, printable PDF schedules and results, tournament history, and an analysis dashboard that suggests a level per player and can track court sides.
- **Secure by design:** passkey and Google sign-in with no passwords, CSRF and origin checks, prepared SQL statements, and a privacy policy written for PDPL and GDPR.
- **Thoroughly tested:** fairness tests across every supported tournament size, plus end-to-end browser tests on Chromium, Firefox and WebKit against MySQL and MariaDB.
